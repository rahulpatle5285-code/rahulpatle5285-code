# Superstore Data Cleaning Project

This project contains a small Superstore sales dataset prepared for analysis.

Files:

- `superstore_cleaning_project.xlsx` - workbook with the original data, cleaned data, summary, and change log.
- `superstore_cleaned_data.csv` - analysis-ready cleaned dataset.
- `superstore_data_cleaning_report.pdf` - short project report.

Cleaning performed:

- Removed two exact duplicate records.
- Standardized dates, whitespace, capitalization, and region/category labels.
- Filled two missing values using consistent information already present in the dataset.
- Converted currency, percentages, and quantities into numeric values.
- Kept negative-profit sales because they are valid transactions.

The raw data is intentionally imperfect for a data-cleaning exercise. The cleaned dataset has 16 records and no missing values in the listed fields.
